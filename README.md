MedProtect

Solucionando proteccion para sistemas de citas medicas

1. Startup y Producto:
   MedProtect es una solución de ciberseguridad enfocada en proteger los sistemas de gestión de citas médicas y proteger la información personal y médica de           pacientes.
   
2. Problemas y Usuarios:
   Los sistemas de citas médicas manejan información personal de los pacientes que puede estar expuesta a diferentes amenazas informáticas, mas que nada el aceso      no autorizado
   MedProtect busca reducir estos riesgos mediante la implementación de medidas de ciberseguridad que protejan la información y la funcionalidad del sistema.
   
   Usuarios principales:
      Pacientes: Personas que utilizan el sistema para consultar y gestionar sus citas médicas.
      Médicos: Profesionales de la salud que administran sus horarios y consultan la información necesaria para sus citas.
      Administradores: Personas responsables de gestionar usuarios, citas y configuraciones del sistema.

3. Roles del Equipo:
    Lider - Tech Lead:
       Operacion: Crear y administrar el repositorio de GitHub, organizar el proyecto y revisar los cambios.
   Responsable de Seguridad:
       Operacion: Conduce el modelo de amenazas y coordina el pentest y la respuesta a incidentes.
   DevOps:
       Operacion: Mantener el servidor y pipelines activados. Mantener las conexiones de API y VM
   Desasrollo Backend:
       Operacion: Construye la API y manejar sus pruebas y su obligacion de encontrar la causa de cada hallazgo y escribe la corrección
   QA y Documentacion:
       Operacion: Comprobacion de funcionamiento y reporte final
   Product Owner:
       Operacion: Habla por el producto y las prioridades y vision sobre el producto
